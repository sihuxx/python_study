# 2차원 배열 문제 풀이

### 1번 ⭐

다음 배열에서 `5`를 출력해봐.

```python
arr = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```
```python
# 정답
arr[1][1]
```

---

### 2번 ⭐

다음 배열의 **모든 값을 출력**해봐.

```python
arr = [
    [1, 2],
    [3, 4],
    [5, 6]
]
```
```python
# 정답
for i in range(len(arr)): # 행 순회
  for j in range(len(arr[i])): # 열 순회
    print(arr[i][j])
```

힌트: `for` 2개 사용

---

### 3번 ⭐⭐

다음 배열의 **모든 값을 2배로 변경**해봐.

```python
arr = [
    [1, 2],
    [3, 4]
]
```
```python
for i in range(len(arr)):
  for j in range(len(arr[i])):
    arr[i][j] = arr[i][j] * 2
```

결과:

```python
[
    [2, 4],
    [6, 8]
]
```

### 4번 ⭐⭐

사용자가 입력한 **3행 3열 숫자**를 2차원 배열에 저장해봐.

입력:

```text
1 2 3
4 5 6
7 8 9
```

결과:

```python
[
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```
```python
arr = []
for _ in range(3):
  arr.append(list(map(int, input().split())))
```

### 5번 ⭐⭐⭐

다음 배열에서 **모든 값의 합**을 구해봐.

```python
arr = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```
```python
sum = 0
for i in range(len(arr)):
  for j in range(len(arr[i])):
    sum += arr[i][j]
```

결과:

```text
45
```
